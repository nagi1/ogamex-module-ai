# Review records

One dated file per review of what the accounts actually did: `YYYY-MM-DD-<scope>.md`. The shape is in
[the review loop](../specs/improvement-loop.md#the-record); the tuning decisions a review produces go
in that page's tuning log, and material changes go in [DECISIONS.md](../DECISIONS.md).

Nothing here is written speculatively. A review record exists only when a window has been read, and the
[10-account pilot of 14 September 2026](../DECISIONS.md#phase-4-pilot-run-at-10-accounts-14-september-2026)
is the last run whose figures are already recorded there rather than here.
