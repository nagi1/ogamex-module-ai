# OGBot (`trilogi77/OgameBot`) — Research Document

Python 3.10+ bot (Playwright/Chromium) that automates OGame: economy, research, fleet, inactive-farming, expeditions, recycling, defence, colonisation, moons and fleetsave, with a Flask-style web panel (`gui.py`/`gui_web/`), Telegram control, Docker multicuenta and persistent JSON/CSV stats. UI strings and comments are Spanish. Committed by two authors (`trilogi77`, `claude`); no releases; no tests in `tests/` — self-checks live as `assert` blocks inside modules and standalone scripts in `scratch/`.

## Overview
- Single-account CLI `main.py` (infinite loop, `--once`, `--config`) + `gui.py` web panel (port 5000) + `Dockerfile`/`docker-compose.yml` (multicuenta, one Chromium per account via CDP ports 9222+).
- Strategy lives in pure, network-free modules; only `client.py` touches the game (Playwright). Architecture diagram in `README.md` §11.
- Modules (`ogbot/`): `gamedata.py` (all game formulas/costs/stats), `models.py` (dataclasses), `config.py` (`@dataclass Config` + YAML/env), `utils.py` (logging, humanisation, rate-limit, Telegram), `universe_api.py` (public XML API), `economy.py` (mine optimizer + facilities + defence), `research.py` (priority/weights/prereqs), `combat.py` (Monte-Carlo battle sim), `targets.py` (farm target valuation + blacklist), `fleet.py` (fleetsave/expedition/recycle/auto-fleet), `moons.py` (moons + colonisation), `startorder.py` (fixed build orders), `prereqs.py` (recursive prerequisite resolver), `stats.py` (`StatsMixin` on `Brain`), `brain.py` (orchestrator, ~3900 lines), `client.py` (Playwright layer), `ogbot/js/*.js` (page-evaluate scraping snippets).

## Architecture & entry points
- `main.py`: `Config.load(config.yaml)` → `Brain(cfg)` → `brain.run_forever()`; PID lock via `bot.pid` (single instance per account). If `config.yaml` missing, launches the GUI.
- `gui.py`: HTTP server (`BaseHTTPRequestHandler`); routes `/api/config`, `/api/start`, `/api/status`, `/api/planets`, `/api/simulate` (combat), `/api/recall`, `/api/control`, `/api/live/*` (CDP screenshot/click/type/drag for CAPTCHA), etc. Frontend `gui_web/index.js` + `index.html`.
- `Brain(StatsMixin)` (`brain.py`) is the orchestrator: `run_forever()` → sleep/wake loop → `cycle()` (configurable round order) → `_continue_until_idle()`.
- `client.GameClient`: login, `_goto(component)`, `read_*`, `build()`, `research()`, `build_ships()`, `build_defense()`, `send_fleet()`, `launch_missiles()`, `recall_fleet()`, message reading. All actions honour `dry_run` via `_act()` (logs `[DRY-RUN]` / `[ACCION]`).
- `universe_api.UniverseAPI`: read-only public XML (`/api/serverData.xml`, `universe.xml`, `players.xml`, `highscore.xml`, `playerData.xml`) with 3600 s in-memory TTL.

## Scheduling & loop model
- `run_forever()` (`brain.py`): sleep interval `random.uniform(cycle_interval_min_s, cycle_interval_max_s)` (600–1500 s default) between cycles; each sleep is broken into small ticks to service: attack re-checks (interval re-rolled each time), `next_expedition_event`/`next_farming_event`/`next_build_event` smart-schedule wakeups, GUI recall/control requests, Telegram commands.
- Active window `utils.within_active_hours(cfg.active_hours)` (default `(8,24)`); outside it the bot sleeps, with optional night attack watch (micro-wakeups every `random.uniform(25,45)` min), optional `_night_sweep` (every `night_sweep_interval_hours`, default 2.0), and a mid-night wakeup that re-logs in, runs `_check_and_escape_attacks()` once and recalls night fleetsaves (`_recall_sleep_fleetsaves`).
- `cycle()`: reads movements + planets (light read using cache), `_process_build_queues()` every cycle, then evaluates independent per-round intervals (`economy_run_interval_mins`, `farming_run_interval_mins`, `expeditions_run_interval_mins`; 0 = every cycle) and runs rounds in `cfg.cycle_order` (default `["economy","recycling","expeditions","farming","feed"]`, drag&drop reorderable).
- `_continue_until_idle()`: after a cycle, polls build/lifeform queues every `POLL = 45` s (bounded by `cycle_interval_min_s`) and enqueues the next construction immediately; also runs attack checks during the wait.

## Decision engine & algorithms
- **Mine optimizer (payback)** — `economy.py`: for each mine `payback = metal_eq_cost / extra_metal_eq_prod_per_hour`; pick lowest payback ≤ threshold. `effective_payback_threshold` = `min(max_mine_payback_hours (168), base*(1 + avg_mine_level/20))` with `base = target_mine_ratio_payback_hours` (default 24, README says 16) unless `adaptive_mine_payback: false`.
- Production formulas (`gamedata.py`): `metal = (30 + 30*lvl*1.1^lvl * eff * (1+0.01*plasma)) * speed`; `crystal = (15 + 20*lvl*1.1^lvl * eff * (1+0.0066*plasma)) * speed`; `deut = 10*lvl*1.1^lvl*(1.44-0.004*max_temp)*eff*(1+0.0033*plasma)*speed`. `eff` = `planet.production_efficiency` read live from `resourcesettings` (captures officers/class/lifeforms/boosters; fallback 1.0).
- **Energy** (`energy_balance`): solar `20*lvl*1.1^lvl`; fusion `30*lvl*(1.05 + energy_tech*0.01)^lvl`; consumption `ceil(10/10/20 * lvl * 1.1^lvl)`; solar sats +25 each.
- **Research** (`research.py`): candidates = priority list × weights; `weighted_cost = cost/weight`; sorted ascending; available research first, lab-blocked cheapest kept as fallback. Recursive prerequisite expansion via `prereqs.resolve_prerequisites` returning the *immediate next step* (building/research/ship).
- **Combat** (`combat.py`): aggregated per-type pools, 6 rounds simultaneous fire, shield pool regenerates each round, shot bounces if `weapon < 0.01*shield`, rapidfire as expected value `(R-1)/R → R shots`, hull = `structure/10`, hull-fraction explosion `if hull_frac < 0.7: deaths = count*(1-hull_frac)` rounded randomly, tech +10%/level; debris = `cost * debris_factor` of destroyed ships.
- **Farm target score** (`targets.py`): `score = loot_value - fuel_value - expected_loss_value + debris_value`; `loot = min(resources*loot_percent, cargo_capacity)`; Monte-Carlo runs=20, must win ≥95%; min `loot_val ≥ min_loot_value`; score must be >0.

## Edge cases & failure handling
- **Fail-closed espionage**: hidden fleet/defense (`data-raw-hiddenships/hiddendef`) → `has_full_visibility=False` → never attack blind; bot re-spies with more probes (+2 per attempt, cap `espionage_max_probes=12`).
- **Positive verification**: `build()`/`research()` require `_verify_started()` (queue active OR upgrade button gone); `send_fleet` verifies navigation to `component=movement` / button still-visible fail-closed; `launch_missiles` verifies IPM stock decreased; `recall_fleet` verifies `data-return-flight`; `rename_planet` confirms name in DOM.
- **Watchdog** `_watchdog_empty_read()`: empty `read_planets` = stale session; re-login at 2/4 empty reads, pause+critical alert at 6 (avoids hammering GameForge lobby).
- **Session recovery**: `_goto` detects lobby redirect and re-logs in; `_empty_read_streak`; storage/state corruption recovered via `.bak`.
- **Mid-night recall**: re-login once mid-sleep, `_check_and_escape_attacks()`, recall deployments (`_recall_sleep_fleetsaves`).
- **Selector canary** `selector_canary()`: checks `#resources`, `#planetList .smallplanet`, eventbox, fleetdispatch link, `.OGameClock` once per process; Telegram alert on failure.
- **Deadlock avoidance**: storage blocker (`startorder.storage_blocker`) forces storage build before a research whose cost exceeds capacity; `savings_reserve` per-resource so one bottleneck resource doesn't block others; `surplus_after_reserve` lets surplus pay cheaper mines while saving.
- **Blacklist / learning**: `targets.blacklist_state` (min_raids 3, avg real loot < min → skip for N days, then reset); `Brain._record_target_loot` accumulates real post-combat loot per target.

## Anti-detection & authenticity
- README warns detection = permanent ban; humanisation reduces but does not eliminate risk.
- Mechanisms: random action delay `human_delay` (triangular `(r1+r2)/2` between min/max), per-hour `RateLimiter(max_actions_per_hour)`, random cycle interval, random attack-check interval re-rolled each time, `active_hours` window, session reuse (`ogame_session.json`, fewer logins → fewer CAPTCHAs), `cycle_order` shuffle-ability, risk profiles, `only_inactive_targets`, `farming_skip_active_targets` (<60 min activity = trap), night micro-wakeups modelled on "looking at phone".
- Browser launch uses `--disable-blink-features=AutomationControlled`, real UA string, `--remote-debugging-port` for the live CDP viewer; optional proxy (`proxy_server`, `OGBOT_PROXY`) for VPS IP blocks.
- Human-outside CAPTCHA resolution: `_wait_for_human_check` / `_await_human_login` wait up to `login_human_check_timeout_s` (300 s) while the user solves via the web viewer; Telegram photo alert throttled 10 min.

## Discrete mechanisms
- M01 — **Mine payback** — build mine with lowest `cost_metal_eq / extra_prod_eq_h`; only if ≤ `effective_payback_threshold` (`economy.py::_mine_payback`/`next_build`).
- M02 — **Adaptive payback cap** — `min(168, base*(1+avg_mine_level/20))` hours (`economy.py::effective_payback_threshold`).
- M03 — **Storage first** — if any resource ≥ `storage_fill_trigger_percent`×capacity (0.90; forced to 0.5 while below 1M min target), build that storage (`economy.py::_next_storage_build`).
- M04 — **Storage capacity formula** — `5000 * floor(2.5 * exp(20*level/33))` (`startorder.py::storage_capacity`).
- M05 — **Energy deficit** — if `energy_balance < 0`: build solar; build fusion only if `deut_synth ≥ 12` and `fusion_reactor < solar_plant - fusion_reactor_solar_offset` (25) (`economy.py::next_build`).
- M06 — **Early robotics** — `robotics_factory < 2 and deut_synth ≥ 3` (`next_build` step 4).
- M07 — **Early shipyard** — shipyard target 1 once `metal_mine ≥ 4` (`next_build` step 2).
- M08 — **Nanite target** — if `robotics_factory ≥ 10 and computer_tech ≥ 10`: `target_nanite = max(0, min(5, 1 + empire_mine_sum//120))` (`brain.py::_facilities_step`).
- M09 — **Metal-dump research** — overflow metal → research `armor_tech` while its metal cost ≤ next `metal_storage` cost, cap `metal_dump_max_armor_tech` (20) (`economy.py::metal_dump_research`).
- M10 — **Save-for-build** — if next build unaffordable and `time_to_accumulate ≤ max_saving_hours_economy` (4 h), set `savings_reserve`; else spend surplus on affordable mines (`economy.py::affordable_build`).
- M11 — **Savings block** — reserve reduced per-resource by what production will replenish while waiting (`economy.py::current_savings_block`).
- M12 — **Server start order** — `SERVER_START_ORDER` in `startorder.py`: metal_mine 2 → metal_storage 1 → solar 1 → metal 4 → solar 2 → crystal 2 → solar 3 → metal 5 → crystal 3 → solar 4 → deut 2 → metal 6 → crystal 4 → solar 5 → deut 3 → robotics 2 → metal 7 → solar 6 → crystal 5 → shipyard 1 → lab 1 → energy_tech 1 → combustion 2 → metal 8 → solar 7 → crystal 6 → deut 4 → shipyard 2 → lab 2 → impulse 1 → crystal 7 → solar 8 → lab 3 → espionage 2 → metal 9 → deut 5 → espionage 4 → impulse 3 → shipyard 4 → astrophysics 1 → metal 10 → solar 9 → crystal 8 → deut 6.
- M13 — **New-colony order** — `NEW_PLANET_ORDER` in `startorder.py`: solar 2 → metal 4 → solar 3 → crystal 2 → metal 6 → solar 5 → crystal 4 → deut 2 → robotics 2 → metal 8 → solar 7 → crystal 6 → deut 4 → shipyard 1 → metal 10 → solar 9 → crystal 8 → deut 6 → metal 12 → solar 11 → crystal 10 → deut 8.
- M14 — **Unlock tree** — `RESEARCH_UNLOCK_ORDER` in `research.py`: energy 1 → computer 5 → combustion 2 → espionage 4 → impulse 3 → astrophysics 1 → combustion 6 → armor 2 → impulse 4 → energy 4 → laser 5 → ion 2 → weapons 1 → energy 5 → shielding 5 → hyperspace 3 → hyperspace_drive 2 → (costly tail) laser 10 → ion 5 → energy 8 → plasma 1.
- M15 — **Research choice** — weighted `cost/weight`, available-first, lab-blocked cheapest as plan B (`research.py::next_research`).
- M16 — **Research caps** — laser 12, ion 5, energy 8, hyperspace 15; energy cap raised to 20 if fusion enabled (`research.py`).
- M17 — **Research time** — `((metal+crystal)/(1000*(1+lab)*speed*2^nanite))*3600` s (`gamedata.py::research_time`).
- M18 — **Build time** — `((metal+crystal)/(2500*(1+robotics)*2^nanite*speed))*3600` s (`gamedata.py::building_time`).
- M19 — **Combat rounds** — 6 rounds, simultaneous fire, shield regen, bounce if `weapon < 1% shield`, hull=structure/10, explode if hull_frac<0.7, tech +10%/level (`combat.py`).
- M20 — **Monte-Carlo** — `monte_carlo(runs=30)`; farm evaluation uses `runs=20`, threshold `win_rate ≥ 0.95` (`combat.py`, `targets.py`).
- M21 — **Auto escort** — greedy by `MILITARY_PRIORITY` (battlecruiser→destroyer→battleship→bomber→cruiser→heavy_fighter→light_fighter), binary-search minimum per type, then `ceil(lo*1.5)` margin (`fleet.py::auto_military_escort`).
- M22 — **Farm score** — `loot_value - fuel_value - loss_value + debris_value`; debris counted only if `farm_recycle_debris` (`targets.py::evaluate`).
- M23 — **Loot cap** — `estimate_loot = min(resources*loot_percent, cargo_capacity)`, proportional across resources (`targets.py`).
- M24 — **Target prefilter** — same galaxy, `min_sys_dist ≤ max_target_distance_systems`, sort by (distance, econ_rank) (`targets.py::select_targets`).
- M25 — **Blacklist** — skip if ≥3 raids and avg real loot < `min_loot_value` within `farming_blacklist_days` (7); reset after window (`targets.py::blacklist_state`).
- M26 — **Suicide probe** — 1 probe on `mission=attack` to create debris, recyclers dispatched with arrival `max(probe_eta+15, attack_eta+60-recycle_ftime)` (`brain.py::_suicide_probe_for_debris`).
- M27 — **Farming cooldown** — `attack_history[coords]` timestamp; skip within `farming_attack_cooldown_hours` (2.0) (`brain.py::_farm`).
- M28 — **Distance** — same galaxy/system: `1000+5*|p1-p2|`; same galaxy diff system: `2700+95*|s1-s2|`; diff galaxy: `20000*|g1-g2|`; same coords = 5 (`gamedata.py::distance`).
- M29 — **Flight time** — `(3500/speed_pct)*sqrt(10*dist/speed) + 10`, divided by `fleet_speed` (`gamedata.py::flight_time`).
- M30 — **Fuel** — `fuel*n*dist/35000 * ((speed_pct*10/10)+1)^2`, +1 (`gamedata.py::fuel_cost`).
- M31 — **Fleetsave** — deploy to moon preferred (invisible to phalanx), speed sweep 10–100%, pick shortest flight ≥ `offline_hours`; fallback expedition to pos 16; `recall_halfway` → target `offline_hours/2` at 10% (`fleet.py::fleetsave_plan`).
- M32 — **Expedition rotation** — system offset sequence 0,+1,−1,+2,−2… mod 499 within ±`expedition_system_range` (`fleet.py::expedition_rotation_system`).
- M33 — **Expedition max find** — `EXPEDITION_METAL_CAP_TABLE` [(10k,40k),(100k,500k),(1M,1.2M),(5M,1.8M),(25M,2.4M),(50M,3M),(75M,3.6M),(100M,4.2M)], top 5M; `max_find = base*eco_speed*1.5(discoverer)*2(pathfinder)*(1+lf_find_bonus)` (`gamedata.py::expedition_max_find_units`).
- M34 — **Expedition cargo** — `ceil(max_find*safety/effective_cargo)`; `effective_cargo = base*(1+0.05*hyperspace)*(1+lf_cargo_bonus)` (`fleet.py::optimal_expedition_cargo`, `gamedata.py`).
- M35 — **Recycler count** — `ceil(total_debris/effective_cargo("recycler"))` (`fleet.py::recycler_count`).
- M36 — **Slots** — `colony_slots=floor((astro+1)/2)`, `expedition_slots=floor(sqrt(astro))`, `fleet_slots=computer_tech+1` (`gamedata.py`).
- M37 — **Moon chance** — `min(0.20, debris/10_000_000)`; `ships_for_debris = ceil(target/((metal+crystal)*debris_factor))` (`moons.py`).
- M38 — **Colony scoring** — `score_position = fields + (30-temp)*0.5`; fields table `{1:96,2:104,3:112,4:143,5:163,6:169,7:163,8:149,9:130,10:114,11:110,12:99,13:90,14:90,15:90}` (`moons.py`).
- M39 — **IPM** — range `impulse*5-1` systems (same galaxy), damage `12000*(1+0.1*weapons)`, silo slots `level*10` (IPM=2, ABM=1); `missiles_needed = ceil(sum(structure*armor+shield*shield_tech)/dmg * 1.25) + interceptors` (`gamedata.py`).
- M40 — **Missile step** — open farms too defended for fleet (win_rate<95%) from existing spy reports, one target/round, best `loot/needed` ratio, max `missile_max_per_target` (60), min `missile_min_loot_value` (150000) (`brain.py::_missile_step`).
- M41 — **Attack escape** — per hostile movement: real attack → `_escape_attack_loc` (sibling planet/moon at 100% if no pending attack there, else remote deploy 10% to farthest); panic-build if impact <5 min and spendable >5000; mission-6 probe → warn only unless `spy_has_attack_fleet` (`brain.py`).
- M42 — **Attack memory** — `recent_attacks["g:s:p:type"] = impact_epoch` so evacuation never lands on a sibling with pending attack (`brain.py`).
- M43 — **Own-fleet recheck** — schedule wake at `arrival+20` if own fleet lands before a pending hostile impact (`brain.py::_next_own_fleet_recheck`).
- M44 — **Rate limit** — `RateLimiter(max_per_hour)` sliding 1 h window; `_guard()` = `rate.allow()+record()+client._delay()` before every action (`utils.py`, `brain.py`).
- M45 — **Defence choice** — `_DEFENSE_LIST` order, build lowest completion %, domes capped at 1, batch `defense_batch_size` (25); night mode skips buffer (`economy.py::next_defense/affordable_defense`).
- M46 — **Auto-fleet targets** — scale `eco = sum(metal+crystal mines)`; economy priority `{cargo: eco*2, lf: eco*2, cr: eco//2, bs: eco//4}`; military `{cargo: eco, lf: eco*4, cr: eco, bs: eco//2}`; expeditions `{cargo: expe_cargo_total+eco, lf: eco, cr: eco//4, bs: eco//8}`; probes 12; recycler `max(4, eco//3)`; colony_ship 1; pathfinders = expedition slots (`fleet.py::auto_fleet_targets`).
- M47 — **Feed** — source planets send surplus above buffer to `feed_target` planets, min `feed_min_send` (5000), rounded up `feed_round_up` (1000) (`brain.py::_feed_step`).
- M48 — **Spy ledger** — one Telegram alert per espionage message, persisted in `spy_notifications.csv`, retry on failure, first-seed backlog suppressed (`stats.py::_process_spy_messages`).
- M49 — **Loot learning** — real combat loot attributed to target coords in `state.json::target_stats` (`brain.py::_record_target_loot`).
- M50 — **Directive rewards** — claim loop (≤30) on `#ipiOverviewTasklist`, abort if state stays `completed` (`client.py::claim_directive_rewards`).
- M51 — **Planet rename** — random non-repeated names per planet/colony (missions 5022/5039), positive DOM verification (`client.py::rename_planet`).

## Notable concerns
- **Gate 1 (static AI) — major violation.** The entire object universe is hardcoded: `gamedata.py` (`BUILDING_COST`, `RESEARCH_COST`, `SHIPS`, `DEFENSES`, `MISSILES`, `BUILDING_PREREQS`, `RESEARCH_PREREQS`, `SHIP_PREREQS`, `RESEARCH_LAB_REQ`, production/speed/cargo formulas), plus `client.py` (`TECH_IDS`, `MISSION_CODES`, `TYPE_CODES`, `_SHIP_NAME_ALIASES`, `SEL` selectors) and `startorder.py` fixed orders. Adding an object/price/requirement requires editing these files — exactly what OGameX gate-1 forbids. Only universe *parameters* (speeds, debris %, loot %, trade ratio) are read from config/API, and production *efficiency* is read live. This is an anti-pattern to copy; the good reusable idea is reading universe params from `/api/serverData.xml` and `Top-1` from highscore.
- **Gate 2 (simplicity) — borderline.** `brain.py` (~3900 lines) plus two overlapping fleet-sizing functions (`size_attack_fleet` vs `size_attack_fleet_for_planet`), many parallel reading paths and ~200 config keys. It is large but mostly justified by scope; `ponytail:` comments name ceilings (e.g. fixed lifeform cooldown, linear fleet heuristic, conservative IPM estimate). The single biggest over-engineering risk to *copy* is the number of knobs — not the mechanisms.
- **Gate 3 (human-authenticity) — several non-human behaviours.** (1) Suicide probe on `attack` mission purely to spawn a debris field for recyclers (`_suicide_probe_for_debris`); (2) panic-build dumping all spendable resources into defence when attacked <5 min; (3) fleetsave computed to exact offline-hours with precise speed selection; (4) farming-with-probes raids; (5) deterministic spy→wait→attack pipeline each cycle capped at 8; (6) night micro-wakeups on a 25–45 min random clock; (7) auto-renaming planets to complete directives. Human-plausible: active-hours window, probe escalation +2/try, activity<60 min trap skip, moon-preferring fleetsave, only-inactive targets.
- Hardcoded locale/selector layer (`client.py` `SEL`, ship-name aliases ES/EN) means any GameForge UI change breaks scraping — mitigated by the selector canary.
